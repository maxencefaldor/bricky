# bricky

The core of [bricky](https://github.com/maxencefaldor/bricky), a compiler-style toolkit that lets AI agents design buildable LEGO® models.
The package holds the exact geometry, the parts catalog, the model format, the checks, the renderer and the `bricky` command.
The [documentation](https://maxencefaldor.github.io/bricky/) covers each of them.
